# Workspace agent instructions

Read [the skill manifest](.psdc/agent-skills.yaml) and its pinned common skill
policy before assessing the ecosystem. Start at [README.md](README.md),
[repos.yaml](repos.yaml), and [Platform Home](<00 - Platform Home.md>).

This workspace owns navigation, the repository catalog, generated views, and
evidence pointers. The Decision Register, accepted ADRs, and contracts in
`psdc-architecture` govern product behavior. Reconcile catalog dependencies
against the accepted dependency contract before changing them. Each product and
institution repository is an independent Git repository with its own change
scope. A dashboard or skill assessment cannot promote documentation into
implementation or deployment evidence.
